# Authored content sources

Phase 0B builds **the pipeline and the contract**, with a **minimal placeholder bundle**
sufficient to prove validation, build, versioning and resolution end to end (§10.3).

`placeholder.json` is that bundle. It exercises every blocking check in §10.2 — key format and
uniqueness, reference resolution, range sanity, and the exactly-five unlock-set cardinality — and
deliberately carries **no creature, item or hunt content**. That is Phase 2 and later (§19).
